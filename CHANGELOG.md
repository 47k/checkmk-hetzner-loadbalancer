# Changelog

## 0.1.0 (development)

- Implement Checkmk 2.5 special-agent, ruleset, agent-based checks, and graphing APIs.
- Add multi-Load-Balancer, multi-service, and multi-target discovery.
- Add target health checks with explicit frontend/backend semantics.
- Add latest-sample performance collection with null metric handling.
- Add isolated API and per-Load-Balancer metrics error handling.
- Add fictional fixtures and automated coverage for TCP and HTTP/HTTPS configurations.
- Derive target/service health associations only from API-provided health entries.
- Reject metric samples older than 120 seconds on a per-series basis.
- Enforce Checkmk Secret transport in the server-side call.
- Omit synthetic unknown LB status, add algorithm to the general summary, and simplify target item identities.
- Show available target IP addresses in target-health summaries without using them as server identities.
- Add configurable result caching, enabled by default with a 60-second TTL and visible stale-on-error fallback.
- Limit stale fallback to 900 seconds by default and centralize stale-cache alerting on the API service.
- Add an open-connections Perf-O-Meter and historical aggregate/per-target health metrics and graphs.
